FAQ

> How can I customize the keyboard shortcut?

This extension provides an cmd/ctrl + shift + k keyboard shortcut you can use to show/hide the command bar. To customize the keyboard shortcut, go to the Chrome "Keyboard shortcuts" page by navigating to `chrome://extensions/shortcuts` in a browser tab. Find this extension on the list and click the edit button to set your own custom keyboard shortcut.
