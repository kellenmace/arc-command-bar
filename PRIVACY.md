# Arc Command Bar Privacy Policy

_Last updated: November 4, 2026_

Arc Command Bar is a Google Chrome extension that lets you switch tabs, open websites, search your browsing history, and run web searches from a keyboard-driven command bar. This policy explains what data the extension uses and what it does with it.

## Summary

Arc Command Bar does not collect, store, sell, or share your data. Everything it reads stays on your device and is used only to show results in the command bar while it is open.

## Data the extension reads

To show results, the extension reads the following from Chrome when you open the command bar or type into it:

- **Open tabs:** the titles and URLs of your open tabs, so you can search for and switch to them.
- **Browsing history:** history entries that match what you type, so you can reopen pages you've visited.
- **Most visited sites:** the list of frequently visited sites Chrome shows on the New Tab page, to rank those sites higher in results.
- **Favicons:** site icons from Chrome's local favicon cache, shown next to results.

This data is processed in memory inside the extension, only to display results. It is not saved by the extension, and it is never sent to the developer or any third party.

## Data shared with websites

The extension only sends data to a website when you choose a result:

- **Web search:** your search text is passed to Chrome, which searches with the default search engine you've chosen in Chrome's settings.
- **Site search:** when you use a site search (for example, YouTube or Wikipedia), your search text is included in the URL of the site you're opening.
- **Opening a URL:** the address you enter is opened in a new tab.

These are the same requests your browser would make if you searched or typed the address yourself.

## What the extension does not do

- No analytics, tracking, or advertising.
- No accounts, cookies, or remote servers.
- No remotely hosted code.
- Websites you visit can't read the command bar's contents or what you type into it. The command bar runs in an isolated extension frame.
